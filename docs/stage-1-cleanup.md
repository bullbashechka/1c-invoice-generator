# Очистка Python-службы — 7 октября 2026 года

## Объём и основание

Пользователь исключил Python из реализации интеграции. Очищается отвергнутая ветка внешней Python-службы; замена механизма открытия карточки и возврата ссылки в эту правку не входит. Требования к десктопному Б24, ручному сохранению задачи и связи один к одному сохраняются.

Применён `codebase-cleanup-audit` из `.agents/skills/codebase-cleanup-audit/SKILL.md`. Перед правкой `git status --short` показывал только чужие неотслеживаемые `.agents/` и `skills-lock.json`; они сохраняются. Исследование зависимостей выполнено read-only разведчиком `code-scout`.

## Порядок и ограничения

1. Зафиксировать аудит и отмену сервисной ветки в документации.
2. Удалить Python-службу и только зависящие от неё тесты; оставить короткий README на прежнем пути для исторических ссылок.
3. Удалить экспорт доступа службы из JS-страницы и его тест; сохранить остальные команды диагностики.
4. Проверить оставшиеся тесты, XML, ссылки страницы на локальные скрипты, хеши исторических BSL-копий и diff.

Из исходников расширения ничего не удаляется. Его старый HTTP-адаптер всё ещё зависит от отсутствующей службы: при включённом `enabled` возможна ошибка `service_unavailable` и незавершённая локальная операция. Такой адаптер не является выбранной реализацией без Python. Установленные настройки демобазы, регистрация Б24 и запущенные процессы этой правкой не меняются; их актуальное состояние не проверяется. Новая поставка CFE не создаётся.

`PRD.md` сохраняется без попутной правки. Его прежняя схема SQLite/service больше не выбирается для реализации по решению пользователя от 7 октября. Исторические результаты в `TASKS.md` и `stage-1-prototypes.md` не аннулируются; прежние команды и ссылки на удалённые `.py` относятся к старым ревизиям Git.


SHA-256 двух исторических копий BSL совпадают. Сгенерированные `__pycache__` только в каталогах службы и её проверок удалены. BSL/XML, EPF/CFE, PRD, Toolkit, пользовательские `.agents/` и `skills-lock.json` не изменены. Рефакторинг реализации не выполнялся.
