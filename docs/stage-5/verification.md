## Проверка при подготовке комплекта

- Архив собирается из явного списка: один CFE, зафиксированные XML/BSL, пять файлов документации/настроек, корневой указатель, manifest и контрольные суммы. Произвольное содержимое `.local` не копируется.
- XML разобран, текстовые файлы прочитаны как UTF-8, пример JSON проверен по текущему контракту настроек.
- После упаковки проверены состав ZIP, CRC и SHA-256 каждого файла; исходники сверены с содержимым указанного коммита, CFE — с указанной контрольной суммой.
- Передаваемые текстовые файлы и бинарник проверены на совпадение с доступным локальным секретом, а тексты — на наличие реальных URL входящих вебхуков. Значения секретов не выводились и не записывались.
- По составу нет баз, выгрузок данных, локальных настроек или журналов. Проверка текста и поиск в сырых байтах CFE не являются полным аудитом упакованного внутреннего содержимого бинарника. Независимое доказательство отсутствия скрытых данных в CFE не заявляется.
- `git diff --check` выполнен. TASKS.md, PRD.md и исходники расширения не изменены.
