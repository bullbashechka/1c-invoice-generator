## Проверка при подготовке архива

- Архив собран из явного списка: один новый CFE, текущие XML/BSL, семь файлов документации/настроек, README, manifest и SHA256SUMS. Базы, локальные настройки, секреты, журналы и Toolkit не включены.
- XML разобраны, текстовые файлы прочитаны как UTF-8, пример настроек JSON проверен. После упаковки состав ZIP, CRC и SHA-256 каждого файла сверены с исходными байтами.
- Тексты проверены на реальные URL входящих вебхуков и приватные ключи. Поиск в текстах и сырых байтах CFE не является полным аудитом внутреннего формата бинарника.
- Код продукта и ранее собранный CFE при упаковке не менялись. PRD.md и TASKS.md не изменены.
