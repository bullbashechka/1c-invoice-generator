# Как запустить расширение 1С → Битрикс24

## 1. Загрузить расширение

Под администратором, после резервного копирования базы и выхода сотрудников:

1. Открыть **«Функции для технического специалиста → Стандартные → Управление расширениями конфигурации»**.
2. Загрузить **`extension/b24-list-forms-fix-20261012.cfe`**. Если `Б24ПрототипЭтап1` уже установлено — обновить существующее расширение из файла.
3. Включить **«Активно»**, выключить **«Безопасный режим» только у этого расширения**, оставить **«Защиту от опасных действий»** включённой.
4. Закрыть 1С и войти заново. При ошибке совместимости установку остановить.

## 2. Заполнить настройки

Это **регистр сведений, а не константа**. Открыть **«Функции для технического специалиста → Регистры сведений → `Расш1_НастройкиОбменаБ24`»**. В меню он может называться **«Расш1 связи заказов б24»**.

У нужного регистра есть поля **«Заказ»**, **«Значение»**, а в записи — **«Секрет»**. **«Заказ» здесь означает ключ настройки.** Создать записи или открыть существующие:

| Заказ (ключ) | Значение | Секрет |
| --- | --- | --- |
| `stage2Enabled` | Сначала `false` | Пусто |
| `rest` | Весь JSON ниже, одной строкой | Свой полный URL вебхука |

В поле **«Значение»** записи `rest` вставить:

```json
{"portal":"https://toofirmagem.bitrix24.kz","groupId":6,"creatorId":26,"responsibleId":12,"accomplices":[10],"auditors":[28,30],"maxTitleLength":250}
```

Копировать только строку JSON, без символов `¶`. В поле **«Секрет»** вставить свой вебхук вида `https://toofirmagem.bitrix24.kz/rest/ID_ВЛАДЕЛЬЦА/ВАШ_СЕКРЕТ/` с `/` в конце. Вебхук в JSON не вставлять. Нужны разрешения `task`, `user_basic`, `sonet_group` и доступ владельца к проекту и задачам. Сохранить запись.

## 4. Включить и проверить

1. В записи **`stage2Enabled`** заменить значение на **`true`** и сохранить. `true` и `false` вводить без кавычек.
2. Войти в 1С заново. Открыть **«Продажи → Заказы клиентов»**: после «Клиент» должна быть колонка **«Задача Б24»**.
3. В карточке заказа нажать **«Создать задачу в Битрикс24»**. Заказ сначала проводится, задача создаётся в фоне; результат — уведомление и ID задачи. Обычные «Записать» и «Провести» задачу не создают.

Служебные записи, включая `baseId`, не удалять и из демобазы не переносить. При обновлении сохранить действующий вебхук. Для временного отключения снять «Активно» у расширения и завершить сеансы сотрудников.

Проверенная среда: **1С 8.3.23.2040, КА для Казахстана 2.4.5.18**. [Проверки и ограничения](stage-5/verification.md).
