# MCP для 1С

Комплект хранится в этом проекте и переносится вместе с ним на другой компьютер. На компьютере должна быть установлена 1С:Предприятие и доступна нужная база.

## Готовые обработки

| Компьютер | Файл для открытия в 1С |
| --- | --- |
| macOS | `MCP_Toolkit_macos.epf` |
| Windows, 64-разрядный клиент 1С | `toolkit/build/MCP_Toolkit.epf` |
| Windows, 32-разрядный клиент 1С | `toolkit/build/MCP_Toolkit_x86.epf` |

Выбирайте разрядность обработки по клиенту 1С. Готовой обработки со встроенными компонентами для Linux в этом комплекте нет.

## Запуск встроенного сервера

1. Откройте нужную базу в 1С:Предприятие.
2. Через «Файл → Открыть» откройте обработку из таблицы выше.
3. Выберите режим «Встроенный сервер» и нажмите «Запустить сервер».
4. Подключите MCP-клиент на этом компьютере к `http://127.0.0.1:6003/mcp`. Если в форме выбран другой порт, используйте его.

В этом режиме Python не требуется. Обработка и сеанс 1С должны оставаться открытыми. Подключение MCP-клиента на каждом компьютере настраивается отдельно.

## Режим Python-прокси

Исходники прокси и зависимости находятся в `toolkit/`. Порядок запуска и подключения обработки описан в [документации Toolkit](toolkit/README.md).

## Состав комплекта

`toolkit/` содержит исходники, готовые Windows-обработки, документацию и лицензию стороннего 1C MCP Toolkit. macOS-обработка лежит рядом с этой инструкцией. Сборки включены как имеющиеся локальные файлы; запуск на других компьютерах пока не проверен.

`1c-mcp-toolkit/` — первоначальный отдельный клон для локальной работы. Он исключён из Git; переносимый комплект находится в `toolkit/`.
