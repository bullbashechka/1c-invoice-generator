# 1c-invoice-generator

Обработка 1С для открытия задач Bitrix24 и материалы проекта.

7 октября 2026 года Python-служба исключена из реализации и удалена вместе с зависимыми тестами. Сохранены BSL/XML расширения и диагностика Б24. Сохранённый BSL-прототип пока содержит прежний сервисный адаптер; сквозной сценарий без службы не реализован. [Аудит очистки](docs/stage-1-cleanup.md).

## Актуальный файл от программиста — 13 октября 2026 года

Переданный пользователем CFE сохранён без изменений: [`extension/Б24ПрототипЭтап1.cfe`](extension/Б24ПрототипЭтап1.cfe). Его полная штатная XML/BSL-выгрузка, включая роль и права: [`src/stage-1-programmer-20261013/`](src/stage-1-programmer-20261013/README.md). Это актуальный исходный снимок присланного расширения; `src/stage-1-prototype/` сохраняет прежние исходники для сравнения. Происхождение, контрольные суммы, способ выгрузки и границы проверки описаны в README снимка.
