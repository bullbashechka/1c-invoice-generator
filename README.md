# 1c-invoice-generator

Обработка 1С для открытия задач Bitrix24 и материалы проекта.

## MCP для работы с 1С

Готовые обработки для macOS и Windows, исходники Toolkit и Python-прокси находятся в [`mcp/`](mcp/README.md). Эта папка входит в проект и переносится при клонировании репозитория.

Порядок запуска на другом компьютере: [инструкция MCP](mcp/README.md).
