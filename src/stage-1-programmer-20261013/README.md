# Исходный снимок CFE от программиста — 13 октября 2026 года

Полная иерархическая выгрузка переданного пользователем [CFE](../../extension/Б24ПрототипЭтап1.cfe), выполненная штатным Конфигуратором 1С 8.3.23.2040 на macOS. Пользователь обозначил этот CFE как актуальную версию после правок программиста. Старый каталог `src/stage-1-prototype/` сохранён для сравнения; дальнейшие изменения присланной версии следует начинать с этого снимка.

Исходный бинарник: 110289 байт, SHA-256 `7ff80389c1542cc073ec4c184e88926cc31578d2a8b3b6dcb4e02ad8d3939aff`. Файл `export-manifest.json` содержит контрольные суммы всех 46 файлов штатной выгрузки; README и сам манифест не входят в этот перечень.

## Содержимое и сохранность

Выгружены 35 XML-файлов и 11 BSL-модулей: метаданные расширения и объектов, формы, общие модули, модули документа, набора записей и управляемого приложения. Сохранены штатный формат, UTF-8/BOM, переводы строк, имена, UUID, привязки форм и совместимость расширения 8.3.21.

Роль `ГЕМ_ОсновнаяРоль` находится в `Roles/ГЕМ_ОсновнаяРоль.xml`, её права — в `Roles/ГЕМ_ОсновнаяРоль/Ext/Rights.xml`. Роль указана в `Configuration.xml` как основная. В файле прав присутствуют семь регистров расширения и 28 разрешений: `Read`, `Update`, `View`, `Edit` для каждого регистра. Это содержимое присланного CFE, перенесённое без изменения. Назначения ролей пользователям, профили доступа и настройки подключения расширения в конкретной информационной базе не являются содержимым этого снимка.

По сравнению с прежними исходниками роль `Расш1_ОсновнаяРоль` заменена на `ГЕМ_ОсновнаяРоль`; изменены метаданные четырёх общих модулей, семи регистров и форма документа. Все 11 BSL-модулей совпадают с прежними при сравнении текста с одинаковыми переводами строк и без BOM. Поведение кода при получении файла не изменялось.

## Способ выгрузки

Создана отдельная пустая файловая база в `/private/tmp` только для технической загрузки и выгрузки. КА Демо и рабочие базы не изменялись; расширение не запускалось в режиме Предприятия, REST не вызывался. Основная конфигурация КА во временную базу не загружалась.

Последовательность команд Конфигуратора, где `<база>` — временная пустая база, `<CFE>` — исходный файл, `<каталог>` — каталог выгрузки:

```text
1cv8 CREATEINFOBASE 'File="<база>";' /DisableStartupDialogs /Out <лог>
1cv8 DESIGNER /F <база> /LoadCfg <CFE> -Extension Б24ПрототипЭтап1 /DisableStartupDialogs /DisableStartupMessages /Out <лог>
1cv8 DESIGNER /F <база> /DumpConfigToFiles <каталог> -Extension Б24ПрототипЭтап1 /DisableStartupDialogs /DisableStartupMessages /Out <лог>
```

Исполняемый файл: `/opt/1cv8/8.3.23.2040/1cv8`. Полная штатная выгрузка включает метаданные и права, а не только текст модулей: [документация 1С](https://kb.1ci.com/1C_Enterprise_Platform/1C_Enterprise_Platform_Overview/Rapid_development_environment/Dumping_and_restoring_configuration_files/?language=en).

## Проверки и ограничения

Копия CFE сверена с присланным файлом побайтово и по SHA-256. Все 35 XML-файлов разобраны XML-парсером, проверены ссылки и UUID всех 26 объектов из `Configuration.xml`. Все 46 файлов в репозитории побайтово совпадают с первой штатной выгрузкой; контрольные суммы манифеста проверены.

Для проверки обратной загрузки выполнены `/LoadConfigFromFiles <каталог> -Extension Б24ПроверкаВыгрузки` и повторная `/DumpConfigToFiles`. Все 45 файлов содержимого, включая BSL, формы, метаданные объектов, роль и `Rights.xml`, совпали побайтово. В `ConfigDumpInfo.xml` изменились только служебные атрибуты `configVersion`; после их исключения документ совпадает, имена и ID сохранены. Затем `/DumpCfg` успешно собрал отдельный проверочный CFE из загруженных XML/BSL. Исходный CFE в `extension/` сохранён без изменений.

Проверочный CFE повторно загружен через `/LoadCfg -Extension Б24ПроверкаCFE` и полностью выгружен через `/DumpConfigToFiles`. Результат снова совпал по всем 45 файлам содержимого, включая роль и права; в `ConfigDumpInfo.xml` отличаются только `configVersion`. Все операции платформы завершились с кодом 0. Пересобранный файл: 109738 байт, SHA-256 `69999eb84b11b2700ef7a5a448f76e2f0613542aa1f67080993a66864002882d`; он использован только для проверки и не заменяет оригинал. SHA-256 файла прав: `ad3c6a965abb37a09151f7b7b43e4a6990b662135a3ccce49131335a34c81041`.

Это проверка переноса артефакта. Применимость к КА, синтаксис в контексте её заимствованных объектов, эффективные права сотрудников и работа REST этой версии здесь не проверены. Требования PRD и результаты прежних прогонов не заменяют такие проверки.
