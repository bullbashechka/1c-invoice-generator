# Python-служба исключена

7 октября 2026 года пользователь исключил Python из реализации интеграции. Восемь модулей службы и одиннадцать зависимых тестов удалены. Этот README оставлен для исторических ссылок.

[Аудит и границы очистки](../../docs/stage-1-cleanup.md). [История фактических проверок](../../docs/stage-1-prototypes.md).

Сохранённый BSL-прототип пока содержит адаптер прежней HTTP-службы. Его сервисный обмен больше не является выбранным решением; готовый механизм открытия карточки и возврата ссылки без Python этой очисткой не реализован. Настройки установленной демобазы и приложение Б24 не менялись.
